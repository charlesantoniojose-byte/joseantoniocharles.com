Process Simulation Software

procsim — From-Scratch Process Simulation Engine

Python Peng-Robinson EOS Tkinter Streamlit SciPy

A process simulation engine built from first principles — modeling the same class of steady-state and dynamic problems commercial tools like Aspen Plus and DWSIM solve — to connect numerical methods, thermodynamics, and process control theory into working software.

  • Thermodynamics: Peng-Robinson equation of state, validated against textbook worked examples (Smith/Van Ness/Abbott/Swihart) for molar volume and Rachford-Rice flash calculations.
  • Unit operations: flash drum, mixer, splitter, heater, and pump models, each with a full dynamic (holdup + energy balance) formulation in addition to steady state.
  • Flowsheet solver: multi-unit flowsheets connected via a directed graph, solved sequential-modularly with automatic recycle-loop detection and convergence — the same algorithm class used by commercial simulators.
  • Process control: PID level and pressure control loops wired directly into the dynamic simulation.
  • Desktop GUI: a Tkinter interface with a drag-free auto-layout flowsheet canvas, restyled to match real ISA-5.1/P&ID drafting convention (monochrome, black-outline equipment icons) rather than generic shapes, backed by a 169-item equipment catalog spanning 16 standard PFD/P&ID categories.
  • Web GUI: a parallel Streamlit front end for the same simulation engine, for browser-based access without the desktop app.
