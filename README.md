# Jose Antonio Charles — Professional Website

Personal portfolio site for Jose Antonio Charles, Chemical Engineer specializing in process safety and risk assessment.

Static HTML/CSS/JS — no build step required.

## Structure

- `index.html` — page content
- `css/style.css` — styles
- `js/script.js` — nav toggle + footer year

## Deploying to GitHub Pages

1. Create a repo on GitHub named `jose-charles-chemical-engineer.github.io` (for a root-domain URL) under the `Jose-Charles-Chemical-Engineer` account.
2. Push this project to the `main` branch.
3. In the repo's **Settings → Pages**, set the source to deploy from the `main` branch, `/ (root)` folder (this is automatic if the repo is named `<username>.github.io`).
4. Site will be live at `https://jose-charles-chemical-engineer.github.io/`.

## Updating content

Edit `index.html` directly — experience, skills, and education are plain HTML blocks with no templating.
