Independent R&D Project

APEX: A Process Simulation Engine Built from First Principles

  • Python
  • Peng-Robinson / SRK EOS
  • SciPy
  • pytest

01Challenge

Understand commercial simulators from the inside by building one: thermodynamics, flash, unit operations, recycle convergence, and process control, each verified against independent references.

02Approach

  • Implemented Peng-Robinson and SRK cubic equations of state with PT/PH flash and phase-stability analysis.
  • Modeled flash drum, mixer, splitter, heater, and pump units in steady state and in dynamic holdup form, with PID level and pressure control.
  • Solved flowsheets sequential-modularly with Wegstein-accelerated recycle convergence.
  • Verified on four levels: symbolic math (SymPy), numerical conservation, experimental reference data (CoolProp, GERG-2008), and an independent code (thermo).

03Result

  • Vapor pressure within 0.57% AAD of the CoolProp reference (PR, propane)
  • C3/nC4 bubble pressure within 0.30% AAD of GERG-2008
  • Recycle convergence cut from 49 to 23 loop evaluations with Wegstein
  • 330 automated tests; dynamic model 28x faster after profiling
  • Component databank of 431 pure compounds with cited sources

Engineering Philosophy

  1. Hazards before solutions. Understand how a system can fail before deciding how to protect it. Controls should trace back to a specific initiating event.
  2. Verify, then trust. A model or calculation is only as good as the check against an independent reference. I test my own work the way an auditor would.
  3. Write it for the next engineer. Safety-basis documents and MOC packages outlive the people who write them, so they have to stand on their own.
